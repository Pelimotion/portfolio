# OUTPUT STRUCTURE — generate all 6 blocks in order

## BLOCK 1 — PROJECT TITLE
Format: [Project Name] — [What it is, result-oriented]
Rules:
- Max 60 characters
- Lead with the project name, follow with the visual deliverable or outcome
- Never use gerunds ("Creating", "Delivering") — use nouns
- Must contain at least one searchable keyword (Visual System / Motion Branding / Brand Film / VFX / OOH)

Example:
"Funky Room — Live Visual System for OOH & VJ Performance"
"HEO Hospital — Premium Health Brand in Motion"

---

## BLOCK 2 — PLATFORM DESCRIPTION (160 characters max)
Formula: [what was made] + [for whom or context] + [result or differentiator]
Rules:
- Hard limit: 160 characters including spaces
- No adjectives that don't carry information ("amazing", "stunning", "powerful")
- Must feel like a headline, not a caption
- Write 2 versions: pick the one that uses more searchable terms

Example:
"Full motion branding system for a Rio DJ event — OOH screens, VJ set, and social content delivered in 3 weeks."

---

## BLOCK 3 — PROJECT BODY (shown inside the case, no character limit)
Structure must follow this exact order, no headers visible to client — write as flowing narrative:

**[Opening — The Business Challenge]**
1–2 sentences. What was the brand's actual problem or opportunity?
Focus on business/market tension, not the creative brief.
Avoid "the client wanted" — write from outcome backward.

**[The Visual System Solution]**
2–3 sentences. How Pelimotion approached it.
Mention: concept direction, motion language, tools if relevant to craft credibility.
If CGI, AI pipeline, or Art Direction was involved — name it explicitly (these are differentiators for the global market).

**[Execution & Deliverables]**
Formatted as a clean list. Each item = one concrete deliverable.
Use action verbs in past tense: Designed / Animated / Directed / Composited / Rendered.

**[Closing — Signal of Results or Positioning]**
1 sentence. Either a measurable result, a placement ("screened at X"), or a positioning statement.
Never end with a call to action in the body — this weakens the luxury positioning.

# TONE RULES (apply to all blocks)
- Write as a studio, not a freelancer. "We" when describing work. Never "I".
- Never use: "passionate", "creative solutions", "bring your vision to life", "storytelling" alone without context.
- Luxury signal: short sentences carry more weight than long ones. Cut everything that doesn't add information.
- Global market default: write in English. Assume reader is in NYC, London, or Berlin.
- Proof over promise: one real placement or result outweighs three adjectives.
